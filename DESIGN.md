# elmo's Production — Design Reference

## Brand Colours
- Background: #F5F3EF (warm off-white)
- Primary Navy: #1C2B4A
- Accent Orange: #E8944A
- Card Background: #FFFFFF
- Card Shadow: 0 2px 8px rgba(0,0,0,0.06)
- Border Radius: 16px on cards, 20px on buttons/chips

## Typography
- Font: System font (SF Pro on iOS, Segoe UI on Windows)
- App name: "elmo's" in orange #E8944A, "Production" in navy #1C2B4A
- Section labels: uppercase, small, grey, letter-spaced

## Login Screen
- Warm off-white background
- Mountain logo in white rounded square at top
- Time-based greeting (good morning/afternoon/evening)
- Department chips 2x2 grid: Steel, Wood, Upholstery, Dispatching
- Role selector: Boss, Manager, Worker
- 4-digit PIN pad with large rounded square keys
- Selected state: navy filled with white text

## Dashboard
- Fixed left sidebar 240px
- Top bar with title + action buttons
- Department filter tabs
- 5 stat cards in a row
- Overdue alert banner (soft red/pink)
- Needs Attention section
- Machine Load weekly grid
